# Frontend setup

This README is for the Vite + React frontend of LocalChef.

## Prerequisites
- Node.js 18+
- npm

## Quick start

```powershell
cd c:\Users\neera\Documents\localchef\frontend
npm install
npm run dev
```

The frontend will be available at:
- http://localhost:5173/

## Useful commands

Build for production:

```powershell
cd c:\Users\neera\Documents\localchef\frontend
npm run build
```

Run the linter:

```powershell
cd c:\Users\neera\Documents\localchef\frontend
npm run lint
```

## Notes
- The frontend uses Vite and React.
- Frontend dependencies are installed with npm from the package.json file in this folder.
